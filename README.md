# 🚀 Task Manager – MERN Stack Application

A full-stack Task Management Web Application built using the **MERN Stack (MongoDB, Express, React, Node.js)**.

This app allows users to securely register, login, and manage their daily tasks with priorities and status tracking.

---

## 📌 Features

✅ User Authentication (JWT based)  
✅ Signup & Login  
✅ Password Hashing (bcrypt)  
✅ Protected Routes  
✅ Create Tasks  
✅ Update Task Status  
✅ Delete Tasks  
✅ Priority Levels (High / Medium / Low)  
✅ Task Completion Tracking  
✅ Responsive UI  
✅ RESTful API  
✅ Full Stack Deployment Ready  

---

## 🛠️ Tech Stack

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
- bcryptjs
- CORS
- dotenv

### Frontend
- React.js
- React Router
- CSS
- Fetch API

### Deployment
- Backend → Render / Railway
- Frontend → Vercel / Netlify
